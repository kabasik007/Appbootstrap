# Zilla Power Manager — тест економії 150–200 Вт (Windows 11)

## Конфігурація, яку потрібно перевірити

- ОС: Windows 11, відеокарта AMD Radeon RX 6900 (точний XT/не-XT варіант перевірити у Windows).
- Батарея: 4S LiFePO₄, конфігурація JK BMS близько 334 А·год; фізичну ємність не підтверджено.
- Інвертор: KEMOT, потужність зі слів користувача ~1,2 кВт; точну модель і власне споживання виміряти/підтвердити.
- Раніше користувач спостерігав приблизно 150 Вт у мінімальному режимі. Це не вимір, отриманий новою програмою.
- Номінальний запас енергії при припущенні 334 А·год: 12,8 В × 334 А·год = 4275 Вт·год ДО втрат інвертора і резерву.

## Важлива межа вимірів

Показник GPU Total Board Power у AMD Software або LibreHardwareMonitor — НЕ потужність усього комп'ютера від 230 В і не сумарна потужність із батареї. Потужність CPU package також не дорівнює системному споживанню. Для чесного режиму «200 Вт від інвертора» потрібен ватметр 230 В на виході UPS або калібрований вимір від самого інвертора. JK BMS дає DC батарейні вати, а не AC.

## План експерименту

1. Записати `powercfg /getactivescheme`. Закрити ігри, торенти, оновлення й важкі процеси; зафіксувати яскравість/кількість і частоту моніторів.
2. В AMD Adrenalin відкрити Performance → Metrics і показати GPU Total Board Power, GPU Utilization і температури.
3. За бажанням відкрити LibreHardwareMonitor з офіційного GitHub. Перевірити, що там є GPU Power/Board Power і CPU Package Power. Якщо WMI не працює, залишити в Zilla «н/д».
4. Кожен сценарій тестувати 5 хвилин після 2 хвилин стабілізації: початковий Windows; Balanced 80%; Eco 55%; Hard 25%; потім ручний повзунок 40%, 30%, 20%.
5. За однакового навантаження порівняти з усіма моніторами та лише головним. Другорядні можна вимкнути через DDC/CI; головний завжди має залишатися доступним. Для відновлення — кнопку програми або кнопку самого монітора.
6. Під час експерименту перевірити чуйність системи: перемикання вікон, браузер, відео, компіляція. Зупинити агресивну економію, якщо система неприйнятно повільна.
7. Для кожного режиму записати мінімум: вати від UPS/розетки, GPU TBP, CPU Package W (якщо є), CPU load, температуру GPU, кількість активних моніторів і суб'єктивну плавність.
8. Після завершення натиснути «ПОВЕРНУТИ ПОЧАТКОВІ НАЛАШТУВАННЯ». Звірити оригінальний GUID і перевірити налаштування сну Windows.

## Критерії цілі

- Етап A: 200 Вт або менше під обраним типовим робочим навантаженням, система не переходить у сон у керованому профілі, головний екран залишається ввімкненим.
- Етап B: 150 Вт або менше без критичного погіршення чуйності; вимірювати, а не виводити із процента CPU.
- GPU power limit / undervolt не змінюємо з коду без підтвердженої підтримки саме цієї RX 6900, перевірки меж і відкату. Опції FPS cap, Radeon Chill і герцовка монітора можна тестувати окремо в Adrenalin.

## Якщо ПК поводиться дивно

Вийти з програми та перевірити план Windows. У командному рядку адміністратора можна вручну відновити його через `powercfg /setactive <ПОЧАТКОВИЙ_GUID>`. Якщо другорядний монітор не прокидається через DDC/CI, використати кнопку живлення монітора. У програмі немає кнопки «Вимкнути всі екрани», немає sleep/hibernate/shutdown.
