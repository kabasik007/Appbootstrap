ZILLAPLAYER — DOWNLOADER ALPHA / Windows x64
==============================================

Це тестова portable-збірка ZillaPlayer для Windows 10/11 x64.
Підтримуються: локальний аудіоплеєр, 31-band EQ, FFT, бібліотека,
yt-dlp менеджер завантажень, MP3, відео до 1440p (QHD / «2K»),
об'єднання відео й аудіо у MKV через FFmpeg, плейлисти до 200 елементів.

ВАЖЛИВО: сторонні інструменти не включені в архів.
На Windows у PowerShell встановіть:

winget install -e --id yt-dlp.yt-dlp
winget install -e --id Gyan.FFmpeg
winget install -e --id DenoLand.Deno

Після встановлення перезапустіть ZillaPlayer (оновиться PATH).
Як варіант, покладіть yt-dlp.exe, ffmpeg.exe поруч із zillaplayer.exe.

Щоб завантажити:
1. Відкрийте вкладку «Завантаження».
2. Натисніть «Перевірити yt-dlp / FFmpeg». Якщо інструмент не знайдено,
   встановіть його та перезапустіть програму.
3. Вставте URL дозволеного вам медіа.
4. Виберіть профіль: MP3 320k, оригінальне аудіо,
   1440p/MKV, 1080p/MKV або найкраще відео.
5. За потреби ввімкніть режим плейлиста (максимум 200 позицій).
6. Натисніть «Аналіз»: yt-dlp отримає лише метадані перших
   100 позицій без завантаження музики чи відео.
   Натискайте рядки для вибору окремих треків.
   Кнопки «Усі / Жодного» змінюють вибір одразу.
   Якщо аналіз не робити, режим плейлиста завантажує до 200 позицій.
7. Виберіть папку, натисніть «До черги».
7. Можна скасувати завдання або повторити його; історія зберігається
   локально в %APPDATA%\ZillaPlayer\downloads-v1.json.

1440p — це QHD 2560x1440, не кінематографічне DCI 2K.
Не всі сайти/джерела надають відео 1440p. FFmpeg склеює потоки,
не створюючи додаткових деталей. Конвертація MP3 320k
не покращує вихідну якість стисненого аудіо.

Завершені MP3/аудіофайли додаються до музичної черги ZillaPlayer.
Завантажене відео зберігається у вибраній папці.
Окремого відеопрогравача, вибору позицій перед завантаженням
і справжньої паузи поки немає (є Скасувати / Повтор).

Дозволено завантажувати лише медіа, на які ви маєте право і
завантаження яких дозволене джерелом. Обхід DRM не реалізований.
YouTube Music API та Google Music не підключали.

yt-dlp:  https://github.com/yt-dlp/yt-dlp
FFmpeg:  https://ffmpeg.org/
Deno:    https://deno.com/

Якщо є помилка, зробіть скриншот вкладки «Завантаження»,
запишіть версію Windows та повідомте, який інструмент показує
«НЕ ЗНАЙДЕНО». Це alpha, не фінальний інсталятор.

Виправлення інтерфейсу: смуги FFT ростуть ВГОРУ;
у 31-смуговому EQ +12 dB знаходиться зверху, 0 dB посередині,
-12 dB знизу.

Шляхи пошуку yt-dlp / FFmpeg / Deno:
- поруч із zillaplayer.exe;
- tools/ біля програми та tools/ffmpeg/bin;
- Windows WinGet Links та системний PATH;
- деякі стандартні каталоги Windows.
Bundled підтримка означає, що файли можна покласти сюди вручну:
сторонні EXE НЕ входять до ZIP без ліцензійної та SHA-256 перевірки.
Deno може знадобитися для підтримки певних YouTube-екстракторів,
але не блокує всі інші джерела.
