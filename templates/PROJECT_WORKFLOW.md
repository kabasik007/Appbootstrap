# [PROJECT_NAME] — Development workflow

1. **Understand:** read `AGENTS.md`, `docs/PROJECT_BRIEF.md`, `docs/PROJECT_PROFILE.md` and `docs/ARCHITECTURE.md`.
2. **Specify:** write acceptance, edge/error conditions and test approach in a feature spec.
3. **Plan:** keep changes small, identify module boundaries, compatibility and migration risks.
4. **Implement:** build one usable vertical slice; prefer correct and simple over speculative abstraction.
5. **Verify:** run configured checks in `docs/QUALITY-GATES.md`; measure relevant budgets.
6. **Review:** check security, privacy, resource cleanup and regressions.
7. **Record:** explain actual results and update project docs/ADRs.

The selected stack and real commands must be filled in before release. No default technology is mandated by this bootstrap.
