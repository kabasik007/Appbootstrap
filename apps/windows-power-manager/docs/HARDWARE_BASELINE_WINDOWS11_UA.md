## Інтерпретація для економії до 150–200 Вт

1. **Спочатку вимірюємо повну AC потужність на виході KEMOT.** Без ватметра ми не знаємо, чи профіль реально наближає до 200 Вт.
2. RX 6900 XT із декількома активними моніторами та високою частотою кадрів — пріоритет для *порівняльного експерименту*: за однакової роботи перевірити 165 Гц, потім 120 Гц, 60 Гц. Висока частота може збільшувати idle VRAM power на деяких конфігураціях, але величина економії не гарантована. Налаштовувати вручну у Windows або AMD Software; поки **не** керувати частотами з Zilla.
3. Другий великий кандидат — два серверні Xeon плюс пам'ять. Невідомі фактичні package watts, кількість DIMM і поведінка firmware. Потрібні датчики/ватметр. Вимикання одного CPU, BIOS C-states або undervolt не виконувати без окремого плану відкату.
4. **AUTO на 48 потоках** має враховувати найбільш зайнятий логічний потік: 100% на одному потоці може виглядати як ~2% загального CPU usage. Оновлений контролер підвищує ліміт при тривалій високій активності окремого потоку та знижує тільки коли обидва показники низькі.
5. Вимкнення моніторів через DDC/CI фізично залишало їх логічно активними, що пояснює загублені вікна. Для тестів використовувати лише Windows DisplaySwitch із 20-секундним rollback. **Не припускати**, що Primary DISPLAY2 — це фізично бажаний основний монітор; перевірити Identify у Windows.
6. Режими CPU 100/80/55/25% — **перформанс-ліміти**, не частка потужності в ватах. Економія може бути нижчою за очікувану, особливо коли система простоює.

## Правдиві вати RX 6900 XT

Офіційний AMD ADLX API має `IADLXGPUMetrics::GPUTotalBoardPower` (включно з VRAM), але необхідно спочатку перевірити підтримку `IsSupportedGPUTotalBoardPower` у встановленому драйвері. Це ще **не реалізовано** в Zilla. Документація AMD:

- https://gpuopen.com/manuals/adlx/adlx-sdk-references/adlx-interfaces/performance-monitoring/iadlxgpumetrics/gputotalboardpower/
- https://gpuopen.com/manuals/adlx/adlx-_d_o_x__i_a_d_l_x_g_p_u_metrics_support__is_supported_g_p_u_total_board_power/

Тимчасовий шлях: AMD Software → Performance → Metrics → GPU Total Board Power. Це не загальні 230 В системи.
