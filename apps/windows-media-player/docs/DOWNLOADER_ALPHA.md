# ZillaPlayer — Downloader Alpha (P5)

**Статус:** новий модуль `src/downloader.rs` інтегровано в Slint; фактичну підтримку окремих сайтів потрібно тестувати на Windows. Google Music API не підключаємо.

## Інструменти Windows

У вкладці **Завантаження** натисни **Перевірити yt-dlp / FFmpeg**.

- yt-dlp — отримання дозволених медіафайлів і плейлистів.
- FFmpeg — склеювання відео та аудіопотоків, конвертація в MP3.
- Deno — для сучасної підтримки YouTube разом з компонентом yt-dlp-ejs; на інших сайтах може бути непотрібним.

У Windows PowerShell:

```powershell
winget install -e --id yt-dlp.yt-dlp
winget install -e --id Gyan.FFmpeg
winget install -e --id DenoLand.Deno
```

Перезапусти плеєр, щоб оновити PATH. Також можна розмістити `yt-dlp.exe`, `ffmpeg.exe`, `ffprobe.exe` поруч із `zillaplayer.exe` або в підпапці `tools`. **Ці сторонні утиліти не включені до ZIP**; їхню ліцензію/цілісність слід перевіряти окремо. Офіційні актуальні yt-dlp standalone exe зазвичай постачаються із потрібним EJS-компонентом.

## Профілі

| Профіль | Реалізація |
|---|---|
| MP3 320k | `-x --audio-format mp3 --audio-quality 320K` через FFmpeg |
| Аудіо ориг. | `-f ba/b -x --audio-format best`, виділення аудіопотоку без примусового MP3-транскодування через FFmpeg |
| 1440p / MKV | `-f bv*[height<=1440]+ba/b[height<=1440]` + FFmpeg mux |
| 1080p / MKV | те саме з обмеженням 1080p |
| Best / MKV | `-f bv*+ba/b` + FFmpeg mux |

**1440p QHD** — це 2560×1440, «2K» у розмовній назві; кінематографічне DCI 2K — інший стандарт. Якщо джерело не пропонує 1440p, результат обмежується наявними форматами. Перекодування MP3 у 320 kbit/s не підвищує якість вихідного стисненого звуку.

## Плейлисти, черга й історія

- «Одне відео» додає `--no-playlist`; «Увесь плейлист» — `--yes-playlist --playlist-end 200`.
- На цій ітерації **немає вибору окремих позицій плейлиста через Analyze**; максимум 200 за одним URL.
- Обирай URL, профіль та папку, натискай **До черги**.
- Одночасно виконується одне завдання. Стани: Черга, Завантажується, Готово, Помилка, Скасовано, Перервано.
- **Скасувати** завершує поточний yt-dlp; для Windows програма намагається також завершити FFmpeg-дерево через `taskkill /T`. **Повтор** перезапускає скасоване чи невдале завдання. Окремої дії Pause поки немає.
- Журнал зберігається в `%APPDATA%\ZillaPlayer\downloads-v1.json`. Після перезапуску незавершені завдання не стартують автоматично, а залишаються «Перервано».
- Після завершення завантаження MP3/оригінальний аудіофайл додається в локальну чергу ZillaPlayer. Відеофайл залишається в обраній папці; відеопрогравач і каталог відео не реалізовані.

## Безпека / потоки

- Всі зовнішні процеси керуються окремим фоновим Rust-супервізором; музика грає незалежно.
- Немає shell-виконання з URL, немає cookie-export чи обходу DRM.
- Перевіряємо HTTPS/HTTP, обмежуємо довжину URL, відхиляємо localhost, приватні буквальні IP та URL із паролями. **DNS rebinding повністю не усунуто**.
- IPC та історія обмежені за розміром; до 64 завдань, до 200 позицій плейлиста.
- Завантажувати можна тільки власні або дозволені матеріали; технічна можливість yt-dlp не означає дозвіл правовласника чи майданчика.
